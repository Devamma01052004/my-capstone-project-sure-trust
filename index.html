What this project does

Real-time AQI resources publish only a single current snapshot per city — there's no ready-made historical archive to analyse. This project closes that gap by pulling the live data.gov.in AQI feed on a regular cadence and appending each pull to one continuously growing master dataset, rather than relying on a static one-time download.

Why it matters

No historical archive exists

The public feed only ever shows "right now" — anyone wanting a trend has to build the history themselves.

Time-series unlocks real analysis

Seasonal spikes, weekday-weekend shifts and city comparisons only surface once enough days are stacked up.

Air quality is a public health signal

A clean, growing dataset makes it possible to connect pollutant levels back to real everyday exposure.

How the data is collected

  1. 01

    Pull the live snapshot

    Fetch the current CPCB real-time AQI resource from data.gov.in, covering monitoring stations across Indian cities at that moment.

  2. 02

    Clean & timestamp

    Standardise station names, pollutant fields and units, and tag every row with its pull date so each snapshot stays traceable.

  3. 03

    Merge into the master file

    Append the cleaned snapshot to the running dataset, building toward 10,000+ rows of genuine time-series coverage.

  4. 04

    Analyse & visualise

    Explore trends across cities and pollutants using SQL and Python, then surface the findings in Power BI dashboards.
